### Import dell'estratto conto

- Nelle Impostazioni, sotto «Dalla banca», puoi importare l'estratto conto scaricato dall'home banking: CSV, Excel (.xlsx), OFX, QIF o CAMT.053. Il file si legge sul telefono e non va da nessuna parte.
- Soldo riconosce da solo le colonne (data, descrizione, importo, oppure Dare e Avere) e se le ricorda: il file successivo della stessa banca si importa in tre tocchi.
- Prima di importare vedi l'anteprima dei movimenti con la loro categoria. Tocca un movimento per cambiare la categoria, escluderlo o unirlo a quello che avevi già segnato a mano.
- I movimenti già importati non tornano due volte, anche con un estratto conto che si sovrappone al precedente.
- Dopo l'import, «Annulla» toglie tutto.

### Regole delle categorie

- Quando cambi la categoria di un movimento nell'anteprima, Soldo propone di ricordarla: per esempio «la descrizione contiene ESSELUNGA → Spesa». La regola vale subito per gli altri movimenti del file e per i prossimi import.
- Le regole hanno una loro pagina nelle Impostazioni, dove si aggiungono, si cambiano e si eliminano.

### Altro

- Su Android, dall'app della banca puoi usare «Condividi» e scegliere Soldo: si apre l'import con il file già pronto.
- I backup portano anche le regole e il modo in cui si leggono i file della tua banca.
